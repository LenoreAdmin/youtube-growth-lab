# YouTube Growth Lab

YouTube Growth Lab is a channel-owner analytics application operated by Lenore AG. It uses authorized YouTube API data to understand organic channel growth, compare video performance and evaluate content experiments.

The application reads channel and video statistics and authorized YouTube Analytics reports. It does not buy views, generate artificial engagement, or publish, delete or edit YouTube content.

Access to channel analytics requires authorization by the channel owner. The application dashboard requires its separate access token. This public page does not display private channel analytics or collect OAuth tokens.
